## **🚀 Quick Start (Windows)**

### **Option 1: One-Click Start (Easiest)**
Double-click: **`start.bat`**

This will:
1. Start the Flask API backend (port 5000)
2. Start the web server (port 8000)
3. Open your browser automatically

### **Option 2: Manual Start**

**Terminal 1 - Backend:**
```bash
python api.py
```

**Terminal 2 - Web Server:**
```bash
python -m http.server 8000
```

**Then open in browser:**
```
http://localhost:8000
```

---

## **🎯 How to Use**

1. **Start the services** (using start.bat or manual steps)
2. **Open** `http://localhost:8000` in your browser
3. **Enter any website URL** (e.g., `https://www.youtube.com`)
4. **Click "Audit"**
5. **View results** - SEO score, metrics, suggestions
6. **Export report** - Download as TXT or JSON
